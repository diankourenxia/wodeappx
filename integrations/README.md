# wodeappx integrations

| Path | OSS default | Purpose |
|------|-------------|---------|
| [`agent-reach/`](agent-reach/README.md) | Yes | Read-only local internet routes inspired by Agent Reach: web, RSS, YouTube subtitles, Bilibili search, V2EX, and upstream command status |
| [`browseract/`](browseract/README.md) | Yes | Optional BrowserAct MCP extension for user-owned browser workflows |
| [`openwork/`](openwork/README.md) | Yes | Bootstrap upstream OpenWork desktop |
| [`opencode/`](opencode/README.md) | Yes | Runtime MCP config examples (Platform + Project) |
| [`shopify/`](shopify/README.md) | No | WodeAppX Shopify OAuth app, Admin MCP endpoint, official Shopify MCP examples, and confirmed store-management tools |
| [`wodeapp-cloud/`](wodeapp-cloud/README.md) | No | Optional login + platform model provider (product) |

```text
OSS user:
  bootstrap OpenWork → BYOK → optional opencode MCP template → self-hosted WodeApp runtime

Cloud product:
  + apply-wodeapp-cloud-integration → Sign in with WodeApp → ai/v1 credits
```
