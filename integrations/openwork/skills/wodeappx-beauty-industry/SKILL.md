# 美妆行业整机适配 Skill（自进化示例）

本 Skill 证明「换行业」应改写整机体验（导航文案、空会话、能力推荐、默认 Runtime Profile），**不是**在「我的智能体」下挂一条行业条目。

配套：`edition.manifest.json`（壳层换皮声明）。当前由自进化直接改源码演示；后续目标是安装本 Skill 即应用 manifest。

## 何时使用

- 用户在美妆/护肤场景要种草图、卖点文案、成分沟通或短视频脚本
- 演示自进化：把通用工作台改成美妆种草工作台
- 提到小红书种草、面霜/精华/口红套图、口播脚本

## 作业流

### A. 完整种草套装（默认）

用户上传产品图或给出品名说明后，按序交付：

1. **卖点**：3 条可核验卖点 + 1 条禁忌/勿过度宣称提醒（中文）。
2. **种草图**：调用出图工具（优先 `product_visual_batch_image_run`，否则 `ai_generate_image`）。创意偏生活场景 / 小红书种草；产品保真优先。
3. **文案**：小红书短文（钩子 → 痛点 → 卖点 → CTA），用户可见文案不用 emoji。
4. **可选视频**：只要一条 ≤15s → `video_generate`；多镜/分镜 → `wodeapp_video_storyboard_open`。商品短视频禁止 `short_drama.open`。

缺图时先请用户上传产品图或包装图，再出图。

### B. 只要文案

直接输出结构化文案，不强制开图/视频工具。

### C. 成分 / 功效问答

- 有知识库命中：引用 `knowledge_search` 结果（source + updatedAt）。
- 无命中：标明假设，建议用户补充成分表或检测报告；不编造临床结论。

## 合规硬规则

- 不编造价格、库存、获批文号、医学疗效。
- 避免诊断式表述；不承诺治愈、排毒、百分百有效。
- 美白 / 抗衰 / 祛痘 / SPF 等敏感词用可核验、体验向表述。

## 工具提示

编排细节以会话注入的【WodeApp — 编排】为准。鉴权先 `wodeapp_auth_status`。分镜链接用返回的 `taskUrl`，对用户用可点击 Markdown 或裸 https URL。
