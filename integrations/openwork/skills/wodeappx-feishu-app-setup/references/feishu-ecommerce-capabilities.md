# 飞书电商经营能力

## 1. 运行时能力发现

优先读取 lark-mcp 的 `tools/list` 结果。工具与权限会随版本、应用配置和用户授权变化；本文件只定义选择逻辑和经营数据口径。

推荐组合：

- 基础预设：群聊与消息、多维表格、云文档/知识库、成员查询。
- 批量多维表预设：批量新增与批量更新经营记录。
- 任务预设：创建/更新任务、添加负责人和提醒。
- 日历预设：读取主日历与忙闲、创建/更新日程。

WodeAppX 当前推荐值为 `preset.default,preset.base.batch,preset.task.default,preset.calendar.default`。若运行时版本不支持该组合，按实际工具列表降级，并明确缺少的能力。

## 2. 电商数据源映射

| 数据域 | 常见飞书来源 | 建议字段 |
|---|---|---|
| 订单经营 | 多维表格 | 日期、订单号、渠道、SKU、数量、实付、退款金额、状态 |
| 商品库存 | 多维表格、商品文档 | SKU、商品名、类目、库存、可售、成本、售价、负责人 |
| 活动投放 | 多维表格、方案文档 | 活动、渠道、预算、消耗、曝光、点击、转化、GMV |
| 内容素材 | 云文档、知识库、共享文件链接 | 主题、商品、平台、状态、发布时间、图片/视频/文件链接 |
| 客户反馈 | 群消息、客服多维表、复盘文档 | 时间、商品、问题类型、严重度、处理状态 |
| 执行协同 | 任务、日历、成员 | 行动、负责人、截止时间、优先级、验收标准 |

字段名可能不同。先读取字段列表或少量样本，向用户展示映射；未经确认不要把“销售额”“支付金额”“GMV”视为同一口径。

## 3. 周报口径

默认周期为本周一至当前时间。用户可改为最近 7 天或指定日期。

- GMV：对用户确认的成交金额字段求和。
- 订单量：优先按唯一订单号去重；没有订单号时说明使用记录数。
- 客单价：GMV / 有效订单量，分母为 0 时不计算。
- 退款率：必须说明使用“退款金额 / GMV”还是“退款订单 / 订单量”。
- 商品表现：按 SKU 或商品分组，输出 Top、低动销与异常退货。
- 库存风险：依据可售库存、近期销量与补货周期；缺补货周期时只做静态低库存提示。
- 渠道表现：按平台/店铺/来源分组；数据源没有渠道字段时不推断。
- 客户声音：按问题类型与严重度聚类，避免输出不必要的个人信息。

所有环比必须有可比的上一周期数据。没有上一周期时，明确写“暂无可比数据”。

## 4. 周报输出结构

1. 周期、数据源与口径说明。
2. 经营概览：可计算的核心指标及变化。
3. 渠道与商品：贡献、Top、低动销、库存风险。
4. 活动与内容：进展、效果、问题和复用机会。
5. 客户反馈：高频问题、风险升级项和处理状态。
6. 风险与机会：区分事实、推断、待补证数据。
7. 下周行动：负责人、截止时间、优先级、验收标准。

先在对话展示完整草稿。用户确认后，才执行以下一种或多种动作：

- 创建飞书云文档并返回链接。
- 发送群卡片并返回消息状态。
- 回写多维表字段并回读更新记录数。
- 创建任务、提醒或日程并返回目标链接。
- 把确认过的飞书素材链接保存为 WodeApp 数字资产，保留原始飞书来源和关联商品。

## 5. 权限与安全边界

- 读取范围同时受应用权限、用户 OAuth、资源共享和应用可用范围限制。
- 默认使用用户身份令牌处理用户可访问资源；需要应用机器人发消息时核对机器人能力与群权限。
- 不显示 App Secret、访问令牌、Cookie、授权码或配置文件内容。
- 不在用户确认前扩大权限、发布版本、发送消息、回写记录、创建任务或日程。
- 读取到素材链接不等于已经导入；保存数字资产前先展示名称、类型、来源与数量。
- API 返回权限不足时，报告所需能力类别与受影响步骤，不尝试从其他身份绕过。

## 6. WodeApp Runtime 基础工作台

基础工作台使用 `FeishuCommerceWorkbench` Section，模板 ID 为 `feishu-commerce-workbench`。模板在 Skill 完成生产验收前保持隐藏，但可以按 ID 创建项目用于内部联调。

运行时提供以下契约能力：

- 健康与连接状态：区分 `demo` 和 `connected`，不返回任何凭证。
- 经营看板：返回周期、指标、趋势、渠道、商品、异常与自动化流程。
- 异常表单：校验标题、负责人和等级，返回标准化记录。
- 周报：不依赖外部 AI 即可生成确定性草稿，便于离线验收。
- 飞书发送：仅在部署已配置应用凭证且传入目标群 Chat ID 时发送交互卡片。

接口路径和端口不要复制到 Skill。仓库内以 `docs/API_BASE.md` 为真相源，实现以 `runtime-server/src/routes/feishuCommerce.ts` 为准。使用 `scripts/check-feishu-commerce-runtime.mjs` 做联调；带 `--project` 时还应验证已发布项目的 runtime 配置与 Section 类型。

当前边界：平台凭证来自部署环境变量，尚不是客户级多租户连接；飞书事件入口仍以 URL 验证与基础接收为主。需要客户自建应用共用公网回调时，先建设云端连接表、OAuth state 校验、token 加密存储和按 app_id/tenant 区分的事件入口。
