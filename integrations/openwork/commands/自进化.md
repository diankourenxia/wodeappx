## 硬门槛（不得跳过）

1. **先复述方案再动手**：一两句话说明将改什么、改哪些文件、是否触及保护清单；等用户明确同意。同意前禁止除只读与 `snapshot` 以外的写操作。
2. **强制遵循 skill** `wodeappx-self-evolution`（若未加载，先读工作区或 monorepo 内该 skill）：
   - `node wodeappx/scripts/self-evolve-guard.mjs snapshot --label "<一句话>"`
   - 最小编辑
   - `node wodeappx/scripts/self-evolve-guard.mjs verify`（失败则 `rollback <snapshotId>`，不留坏代码）
   - 用户确认生效后：`version commit --label "<说明>"`
3. **不得自行重启应用或杀进程**；主进程 / sidecar 改动须提示用户手动重启。
4. **保护清单**（改前须用户再次明确确认）：`wodeappx/scripts/self-evolve-guard.mjs`、自进化 skill、`vendor/openwork` 的 typecheck / tsconfig。

## 默认推荐意图（白名单优先）

若用户未写清 `$ARGUMENTS`，先询问选一类，勿盲目大改：

- 换 / 微调皮肤（见 `wodeappx/docs/examples/skin-theme-evolve-examples.md`）
- 欢迎文案 / 品牌文案微调
- Live2D / 桌面陪伴开关与问候语（若产品已允许）

外观改动还须过皮肤对比度门禁（`pnpm check:skin-contrast` / live），见示例文档。
