# WodeAppX name and logo

Apache-2.0 covers the source code. It does **not** grant trademark rights.

## Marks

| Mark | Canonical file | Use |
|---|---|---|
| **WodeAppX** (product name) | README / installer `CFBundleName` | Window title, packages, docs |
| **wodeappx** (codename) | package / binary names | Repo, CLI, filenames |
| Wordmark lockup (black field, white “WodeApp”, lime “X”) | `branding/wodeapp-icon-source.png` | App icon, favicon, README |
| README / social sizes | `branding/wodeappx-logo-180.png`, `branding/wodeappx-logo-512.png` | GitHub README, og:image |

Do not use the old WodeApp blue/orange stacked wordmark as the open-source product mark.

## Forks

You may fork, modify, and redistribute the code under Apache-2.0.

You must **not**, without written permission from the trademark owner:

- ship an installer, website, or store listing named WodeAppX / WodeApp as if it were this project;
- use the official lockup, lime-X wordmark, or confusingly similar logos;
- imply the fork is an official build, update channel, or affiliate.

Compatibility statements are fine, for example: “based on WodeAppX” or “compatible with WodeAppX workflows”.

If you publish a fork, pick a **distinct product name, icon, and `appId`**. Keep `com.differentai.openwork` only if you are continuing this exact install lineage (keychain / TCC); that identifier is an implementation compatibility choice, not a trademark license.

## Questions

Open a private note to the repository owner. Do not file a public issue that dumps unreleased brand assets or impersonation reports with personal data.
