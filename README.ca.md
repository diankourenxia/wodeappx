## Què podeu fer

- **Personalitzar l’agent** — skills, eines, MCP, connectors, skins
- **Combinar models** — text, imatge i vídeo cadascun al seu; sense cadenat
- **Imatge i vídeo a punt** — lots, storyboards, imatge a vídeo ja connectats; agents d’imatge / vídeo / short / llenç / multimodel
- **Actius digitals** — deseu imatge i vídeo d’un toc; reutilitzeu-los al xat
- **Automatització del navegador** — l’extensió de Chrome clica, llegeix i captura pàgines reals
- **Skills en lot** — el mateix flux sobre un conjunt; permisos, cost i reintents a la vista
- **Auto evolució** — apunteu l’espai de treball al codi d’aquest producte; l’agent pot canviar l’app (instantània → verificar → revertir)
- **Feina real a l’ordinador** — carpetes, fitxers, terminal, navegador — no només xat
- **Llocs i mitjans poden quedar-se en local** — publicar i produir a la màquina o autoallotjat; el núvol és opcional

Les skills defineixen què pot córrer; l’agent ho executa. Digueu què voleu fer.

## Per què WodeAppX

Cursor / Claude Code / Codex editen el vostre repositori. WodeAppX és un taller d’agent d’escriptori: personalitzeu l’agent, combineu models, porteu tallers d’imatge/vídeo i podeu canviar el producte mateix. El programari és gratuït (Apache-2.0). Només pagueu els models que porteu. Sense mur de subscripció.

- **Vosaltres doneu forma a l’assistent** — skills, eines i skins són de primera
- **El model adequat per a cada feina** — text, imatge i vídeo no han de compartir proveïdor
- **Una línia, no una closca buida** — els tallers d’imatge i vídeo venen a punt
- **Les dades poden quedar-se privades** — sessions, fitxers, terminal i navegador a la vostra màquina; l’OSS arrenca sense login
- **Les vostres claus** — clau local o autoallotjat primer; el núvol oficial és extra, no una porta
- **Pot canviar aquesta app** — l’auto evolució té instantània i rollback
- **Obert i auditable** — Apache-2.0; inspecteu, feu fork, redistribuïu

## Després d’obrir

1. **Clau local (per defecte)**  
   Barra **Local** o **Configurar claus locals**. Valen DeepSeek, Volcano Ark, Kimi / Moonshot, DashScope, OpenRouter (una clau per a GPT / Claude / Grok) i OpenAI connectat.  
   També podeu afegir un **proveïdor propi**: nom + URL base + clau; sondegem `/models` compatible amb OpenAI.  
   Les claus queden a `~/.wodeapp/keys.json` a la màquina. No s’envien a WodeApp.

2. **Chrome (opcional)**  
   Instal·leu l’extensió des de Capacitats perquè l’agent cliqui, llegeixi i capturi pàgines reals. Podeu saltar-ho i instal·lar-ho després.

3. **Núvol (opcional)**  
   Barra **Núvol** i trieu lloc: International [wodeapp.ai](https://wodeapp.ai/) (Stripe) o Xina [wodeapp.cn](https://wodeapp.cn/) (Alipay / WeChat). El login obre el navegador del sistema. WodeApp és un proveïdor més. Entrar no us torna el model per defecte al núvol.

4. **Parlar**  
   Digueu què us cal en un xat buit, o obriu Imatge / Vídeo / Actius / Capacitats. El selector mostra les famílies actuals i les casa amb les claus que heu connectat de debò.

Xat, imatge i vídeo comparteixen claus i encaminament. Si falta una clau, la UI demana configurar-la — no només iniciar sessió.

## Executar des del codi

Node.js 22, pnpm 9.15, Bun 1.3.9+, Go 1.23. No feu servir Node 26. L’ordre és `pnpm run setup`, no `pnpm setup`.

```bash
git clone https://github.com/diankourenxia/wodeappx.git
cd wodeappx
pnpm run setup
pnpm dev
```

`pnpm run setup` porta el shell d’escriptori, aplica pedaços i instal·la dependències. `vendor/` és generat: no el tracteu com a font. Després creeu un espai local i afegiu claus.

Vegeu [CONTRIBUTING.md](CONTRIBUTING.md).

## Preguntes

**Substitueix Cursor / Codex?**  
Sí, i més. Feu servir WodeAppX per al repo, agents, imatge i vídeo, i llocs. Munteu el vostre taller: skills, eines, skins, models. Porteu la vostra clau.

**Cal login al núvol?**  
No. L’OSS funciona amb les claus que porteu. El núvol és opcional.

**L’auto evolució entrena un model?**  
No. Són edicions amb porta del codi d’aquest producte (còpia → verificar → revertir), no entrenar pesos.

**Surten les meves dades d’aquest ordinador?**  
L’OSS és local primer. Sessions i fitxers poden quedar-se a la màquina. Només surten les API de model que configureu. El login al núvol no és una porta.

**Està a punt l’edició visual de skills?**  
Skills / MCP / eines ja corren. L’editor de graf de flux és al full de ruta.

**Windows diu que l’instal·lador no està signat?**  
Windows encara no té Authenticode. macOS està notariat. Podeu executar des del codi o llegir les notes de Releases.
