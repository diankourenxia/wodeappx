# T2 — 一次搜索加载约 5 个工具

目的：触发一次 tool_search，加载一小批 deferred 工具，观察 toolset 从 0 到 ~5 的缓存代价与恢复。
预期行为：Turn 1 内 loaded 0 → ~5，之后 toolset 稳定，cache.read 跌一次后逐步恢复。

## Turn 1

帮我做一份本周电商经营简报，按顺序完成：
1. 查询最近 7 天的销售指标（GMV、订单量、客单价、退款率）；
2. 把指标导出成 CSV 文件；
3. 基于数据写一段 200 字以内的经营结论；
4. 把简报发布出去。
如果缺少完成这些事的工具，先搜索可用工具再执行。完成后告诉我简报里最关键的一个数字。

## Turn 2

刚才那份简报里的退款率偏高，帮我查一下库存周转数据，看看是不是某几个 SKU 积压导致的，把结论追加到 `notes/weekly-plan.md` 末尾。
